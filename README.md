# 住宅価格分析フルスタック・ダッシュボード (Full-Stack Housing Price Analytics Dashboard)

## 概要
統計学的なアプローチを用いて、現実的な不動産市場のダミーデータを動的に生成・分析・可視化するフルスタックアプリケーションです。**Javaによるデータ生成エンジン**、**Djangoによる管理システム**、**Rによる高度な統計解析**を、**Dockerコンテナ上**でシームレスに統合しています。

## アーキテクチャと技術スタック
* **データ生成エンジン:** Java 17 (重回帰モデル + 正規分布ノイズ)
* **Webフレームワーク:** Python 3.10 (Django)
* **統計解析・可視化:** R (ggplot2), Pandas
* **インフラ:** Docker / Docker Compose
* **データベース:** SQLite3
* **フロントエンド:** HTML5 / CSS3 / Chart.js

## コア機能と実装の工夫

### 1. 統計的根拠に基づくデータ生成ロジック (Java)
単なるランダム値ではなく、以下の重回帰モデルに基づいたデータ生成を行っています。

$$y = \beta_0 + \beta_1 x_1 + \beta_2 x_2 + \dots + \beta_n x_n + \epsilon$$

ここで、築年数や駅距離などの変数に加えて、標準正規分布に基づく誤差項 $\epsilon$ を加味することで、統計学的な「尤もらしさ」を持つ実践的なモックデータをJSON形式で生成しています。

### 2. 異種言語・異環境のコンテナ統合 (Docker)
Python、Java、Rという、通常は共存が難しい複数のランタイムを一つのDockerイメージに集約。Dockerfileを工夫し、OSレベルでのパッケージ管理を行うことで、環境構築の自動化とポータビリティを実現しました。

### 3. 多角的なデータ分析パイプライン
* **Python/Pandas:** 平均家賃や相関係数など、ビジネスインサイトの即時抽出。
* **R (rpy2連携):** ggplot2を用いた高度な回帰分析グラフの生成。
* **Chart.js:** ORMで保存した情報のグラフ化。動的な階層づくりを意識し、データセットの変化にも柔軟に対応可能なヒストグラムを実装。

### 2. コンテナのビルドと起動
```bash
docker-compose up --build

### 3. ブラウザでアクセス
http://localhost:8000/ にアクセスしてデータ一覧と分析結果を確認します。
